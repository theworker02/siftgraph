# siftgraph

Sift URLs and graph query parts with stable normalization.

**Site:** https://theworker02.github.io/siftgraph/

## Install / run

```bash
git clone https://github.com/theworker02/siftgraph.git
cd siftgraph
node src/cli.js
node --test
```
